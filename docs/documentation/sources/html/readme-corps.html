3. Conventions de cette documentation

  • Les chemins sont cités depuis la racine du dépôt.
  • Les commandes sont recopiées depuis le dépôt ; celles qui viennent de la pratique de l'autrice sont signalées comme telles.
  • Les variables sont nommées sans valeur ; aucun secret ni adresse de serveur ne figure dans ces documents.
  • Un point qui ne se déduit ni du code ni des constats porte le badge Non déterminé à date et figure en annexe du document.
  • Les constats sont séparés des recommandations ; aucun audit n'a été produit à ce stade.
