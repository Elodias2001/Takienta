# Documentation

Takienta est un projet open source qui expose la structure administrative du Bénin, hors ligne, avec la source de chaque enregistrement. Le paquet s'appelle `benin-geo`, en JavaScript et en Python, avec les mêmes identifiants et les mêmes résultats dans les deux langages.

## Les fiches

- [Démarrer](01-demarrage.html) : utiliser le paquet depuis les sources, premiers appels.
- [Référence de l'API](02-reference-api.html) : les données, les fonctions, la recherche.
- [Modèle de données](03-modele-de-donnees.html) : ce que porte un enregistrement, et ce que veulent dire `officielle`, `derivee` et `provisoire`.
- [Identifiants](04-identifiants.html) : les règles figées, et pourquoi.
- [Contribuer](05-contribuer.html) : les invariants du produit, et ce qui est refusé.

Pour savoir d'où vient chaque chiffre, ouvrez la page [Provenance](/provenance).
